# Govee B5109 Add-ons

Home Assistant add-on repository. Add it in Home Assistant under Settings ->
Add-ons -> Add-on Store -> the three-dot menu -> **Repositories**, using this
repository's URL: `https://github.com/Rake-Pro/homeassistant-govee-B5109`.

The one add-on here is the Govee B5109 MQTT Bridge: see
[govee_b5109/README.md](govee_b5109/README.md) for what it does, install
steps, and configuration.
